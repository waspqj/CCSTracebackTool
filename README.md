# 使用手册

## 1. 工具用途

回溯某产品(QR + 编号)在某天的所有 NG 错图,统计当天的 NG 情况、缺陷分布。
数据来源:

- **MES 日志**(`*.csv`):每条产品检测记录
- **NG 错图**(`*.bmp` / `*.jpg`):实际触发 NG 时抓拍的图像

## 2. 部署

把整个文件夹拷到目标电脑即可运行,无需安装:

```
使用目录\
├── CCS_Traceback.exe
├── Cyotek.Windows.Forms.ImageBox.dll     ← 图片预览控件,必须和 exe 同目录
└── ApplicationSetting.json               ← 路径配置,启动时读取
```

## 3. 配置 ApplicationSetting.json

启动时从 exe 同目录自动读取。**缺失或字段不全会弹错并禁用所有数据按钮**。

```json
{
  "PathMesLog": "D:\\mes日志",
  "NGImgSave":  "D:\\NGImgSave"
}
```

### 3.1 目录约定

**MES 日志**:任意层级下的 `*.csv`,文件名带月份子目录:

```
D:\mes日志\
└── 2026-07\
    ├── 2026-07-28_A.csv
    └── 2026-07-28_B.csv
```

**NG 错图**:按 4 层子目录(月份层可省略):

```
D:\NGImgSave\
└── 2026-07\                    ← 当月(可省)
    └── 2026-07-28\             ← 当天
        └── QR001\              ← 产品二维码(空 QR 时用字面 "0")
            ├── 连接器\
            │   ├── Camera9_3_143052.jpg
            │   └── 螺母错装_143108_0456.bmp
            └── VM\
                └── 焊点偏移_143450_0111.bmp
```

## 4. 启动

双击 `CCS_Traceback.exe`,正常情况直接进入主界面:

- 顶部:`日期`、`从`、`到` 三个时间控件 + 三个数据按钮
- 左中:二维码搜索框 + 搜索结果表
- 右中:统计区文字 + 柱状图
- 左下:NG 行列表(初始显示一行占位文字)
- 右下:图像预览区 + 图像信息区

弹错"加载配置失败" → 回到第 3 节检查 json。

## 5. 使用流程

### 5.1 加载 MES 日志

1. 选**日期**(顶部下拉)
2. 设**时段**:`从` `到` 都填 `HH:mm`,默认 00:00 ~ 23:59(**不可跨天**)
3. 点 **"更新数据"** → 弹出 `载入 M 条记录`
4. "二维码" 和 "编号" 下拉自动列出当天出现过的所有值

> 同一日期 + 时段再点不会重复读 CSV。

### 5.2 按二维码统计

点 **"按二维码统计"** → 弹窗展示所有已载入记录按 QR 汇总的 NG 情况(自带柱状图)。

- **双击** 弹窗任意一行 → 回到主界面,自动填上对应 QR + 编号
- 同一份数据再点只激活已有窗口,不会开新窗
- 改了日期 / 时段重新加载,旧窗口会被关掉重开

### 5.3 扫 NG 错图

**入口有两处**(都用双击触发,没有专门的"扫描文件"按钮):

1. **二维码搜索框** → 输入字符过滤 → **双击搜索结果表里的一行** → 扫该 QR 当天所有 NG 图
2. **统计窗口双击一行**(同 5.2)

扫到的结果填到 NG 行列表,按时间升序排列。

### 5.4 NG 行列表

- 列:`序号` / `检测别名` / `时间` / `NG原因` / `文件路径`
- **双击任意一行** → 右侧预览区加载图片,下方"图像信息区"自动填 QR / 编号 / 缺陷 / 时间
- 支持的图片格式:`jpg` / `jpeg` / `bmp` / `png`

### 5.5 时间显示

NG 文件名尾部形如 `_HHmmss_ffff.jpg`(4 位毫秒段 `ffff`):

- **NG 文件行** → 显示完整 4 位毫秒,例 `03:05:27.4143`
- **CSV 记录行** → 显示 3 位毫秒,例 `03:05:27.143`

## 6. 常见问题

### 6.1 启动报错 "找不到 ApplicationSetting.json"

`ApplicationSetting.json` 跟 `CCS_Traceback.exe` 在**同一个目录**。

### 6.2 启动报错 "文件里没有 PathMesLog 字段"

检查 json 字段拼写(大小写敏感):

```json
{ "PathMesLog": "...", "NGImgSave": "..." }
```

### 6.3 NG 列表是空的 / 没变化

- 入口是 **双击搜索结果表或统计窗的一行**,单击不会触发
- 搜索框关键字输错了,清空后重输
- NGImgSave 里没有当天 + 该 QR 的子目录(目录名大小写不一致也不会匹配)
- 空 QR 对应的目录名是字面 `"0"`,不是空文件夹

### 6.4 双击图片预览失败 / 不显示

- 工具启动后**移动过 NGImgSave 目录** → 重新扫描一次
- 文件被外部进程占用 → 选另一行或稍后再试

### 6.5 顶部三个数据按钮全灰,无法点击

`ApplicationSetting.json` 没加载成功(启动时弹过错),修复后重启软件。

### 6.6 文件名末尾残留中英文逗号 / 下划线 / 连接符

主程序写文件名时只去了英文逗号,扫描器自动清理尾部残留符号:
`焊点偏移,_143450_0111.bmp` → 原因 `焊点偏移`。

### 6.7 NG 列表很长但加载很慢

首次扫描会遍历 NGImgSave 下当天 + 该 QR 目录里的所有图像文件,文件数过万时
请耐心等待(状态栏会显示进度)。扫描结果会按时间排序展示。
