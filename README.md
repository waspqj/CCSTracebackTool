# CCS 检测回溯工具 —— 使用手册

## 1. 工具用途

回溯某个产品(QR + 编号)在某天的所有 NG 错图,统计当天的 NG 情况、缺陷分布。
数据来源有两处:

- **MES 日志**(`*.csv`):每条产品检测记录的原始结果
- **NG 错图**(`*.bmp` / `*.jpg`):检测过程中实际触发 NG 抓拍的图像

## 2. 目录结构

```
项目根目录\
├── CCS_Traceback\
│   ├── bin\Release\          ← 编译产物在这里
│   │   ├── CCS_Traceback.exe
│   │   └── ApplicationSetting.json   ← 必须和 exe 同目录
│   └── CCS_Traceback.csproj
└── README.md
```

## 3. 第一步:获取 exe

如果你是开发者,在 Visual Studio 里:

1. 解决方案右键 → **生成解决方案**(配置选 `Release | AnyCPU`)
2. 生成完后到 `CCS_Traceback\bin\Release\` 找 `CCS_Traceback.exe`

如果你是使用方,直接拿别人编译好的 `CCS_Traceback.exe` 即可。

## 4. 第二步:准备 ApplicationSetting.json

`ApplicationSetting.json` 是配置入口,**必须和 `CCS_Traceback.exe` 放在同一个目录**。
启动时会从 exe 同目录自动读取,缺失或字段不全都会弹错并禁用所有数据按钮。

### 4.2 目录约定

**MES 日志**:`PathMesLog` 下任意子目录的 `*.csv` 文件,文件名带月份子目录,
例如:

```
D:\mes日志\
└── 2026-07\
    ├── 2026-07-28_A.csv
    └── 2026-07-28_B.csv
```

**NG 错图**:`NGImgSave` 下必须严格按 4 层子目录组织:

```
D:\NGImgSave\
└── 2026-07\                    ← 当月
    └── 2026-07-28\             ← 当天
        └── QR001\              ← 产品二维码(空 QR 时用 "0")
            ├── 连接器\          ← processName
            │   ├── Camera9_3_143052.jpg          ← 8 台背面连接器 NG
            │   └── 螺母错装_143108_0456.bmp      ← 旋转 / 侧面 / VM NG
            ├── 铝排\
            │   └── 铝排不合格_143302_0000.bmp
            └── VM\
                └── 焊点偏移_143450_0111.bmp
```

## 5. 第三步:启动软件

1. 确认 `CCS_Traceback.exe` 和 `ApplicationSetting.json` 在同一目录
2. 双击 `CCS_Traceback.exe`
3. 正常情况下:**直接进入主界面**,顶部"二维码"、"编号"下拉为空,中间三个数据按钮(更新数据 / 按二维码统计 / 扫描文件)亮着。
4. 如果弹出"加载配置失败"对话框:回到第 4 步检查 json 文件

## 6. 第四步:加载 MES 日志(更新数据)

这一步骤把指定日期 + 时段内的 CSV 全部载入到内存

1. 选**日期**:`日期` 下拉框点开,选当天
2. 设**时段**:`从` 填 `HH:mm`,`到` 填 `HH:mm`(默认 00:00 ~ 23:59)
3. 点 **"更新数据"** 按钮
4. 弹出提示框 `载入 M 条记录。`
5. "二维码"下拉自动列出当天出现过的所有产品二维码,第一项是"(全部)"
6. "编号"下拉自动列出当天出现过的所有编号

> **重复点击保护**:日期 + 时段完全没变时,再点"更新数据"不会重复读 CSV、不会弹窗。

## 7. 第五步:选产品 + 看统计

### 7.1 按二维码统计(整体 NG 分布)

1. 点 **"按二维码统计"** 按钮
2. 弹出一个新窗口,展示所有已载入记录按 QR 汇总的 NG 情况
3. 窗口**一对一**:同一份数据再点这个按钮只是把已有窗口激活,不会开新窗口
4. 改了日期或时段重新加载后,旧窗口算过期,会关掉重开
> 窗口里 **双击任意一行** → 自动跳回主界面,把对应 QR + 编号填上,窗口本身不关。

### 7.2 选具体产品

1. 在 "二维码" 下拉选具体的产品
2. "编号" 下拉自动过滤到只显示该 QR 对应的编号
3. 在 "编号" 下拉选具体的编号

(同一 QR 可能多次检测)。

## 8. 第六步:扫 NG 错图

1. 选定一个具体的 QR + 编号
2. 点 "扫描文件" 按钮
3. 扫到的结果填到 NG 行列表里

### 8.2 双击预览

1. 在 NG 行列表里 **双击某一行**
2. 右侧预览区域加载图片

## 9. 常见问题

### 9.1 启动报错 "找不到 ApplicationSetting.json"

确认:
- `ApplicationSetting.json` 跟 `CCS_Traceback.exe` 在**同一个目录**

### 9.2 启动报错 "文件里没有 PathMesLog 字段"

确认 json 里的字段名拼写:

```json
{
  "PathMesLog": "...",     
  "NGImgSave":  "..."      
}
```

### 9.3 "扫描文件"后列表是空的

检查:
1. **二维码**和**编号**都选了具体值(没有停在"(全部)")
2. NGImgSave 目录里**确实有当天 + 该 QR 的子目录**和文件存在
3. QR 在 NGImgSave 里没被改名,目录名大小写不一致也不会匹配
4. 空 QR 的目录名是字面 `"0"`,不是空文件夹

### 9.4 双击图片预览失败 / 文件不存在

- 工具启动后**移动过 NG 错图目录**,重新扫一次再点
- 文件被外部进程占用时,预览会失败(选另外一行或稍后再试)

### 9.5 "更新数据"按钮灰色无法点击

- **ApplicationSetting.json 没加载成功**(启动时会弹错)
- 修复 json 后重启软件

### 9.6 中英文逗号 / 下划线在文件名末尾

主程序写文件名时 `TrimEnd(',')` 只去了英文逗号,残留的中文逗号 / 下划线 /
连接符,扫描器做 `CleanReason` 时会一并去掉。例:`焊点偏移,_143450_0111.bmp` →
原因 `焊点偏移`。
